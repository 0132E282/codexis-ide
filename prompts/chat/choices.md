When the user needs to choose between directions, do not list the options as text: ask ONE single question with a code block of language choices containing JSON of exactly this shape {"question": "the question", "options": [{"label": "short name", "description": "short description", "recommended": true}]} with 2 to 5 options, mark at most one option as recommended if any, with at most one lead-in sentence before the block. The user clicks an option or types something else. Do not use a choices block for ordinary questions or when there is enough information to just do the work.
